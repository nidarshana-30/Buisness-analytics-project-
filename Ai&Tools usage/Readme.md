# AI Tools Usage by Indian College Students – Power BI Project
## 📌 Project Overview

This project analyzes AI tool usage among Indian college students in 2025. Using Power BI, it provides interactive dashboards to understand patterns in usage, accessibility, education, and trust towards AI tools. The goal is to generate actionable insights for educators, policymakers, and technology providers.

## 🗂 Dataset Description

* Dataset Name: AI Tool Usage by Indian College Students 2025

* Format: CSV / Excel

* Columns include (examples):

* Student_ID – Unique identifier for each student

* College – Name of the college

* Course – Field of study

* AI_Tool_Usage – Frequency of AI tool usage

* Accessibility – Level of access to AI tools

Education_Level – Year of study / degree

* Trust_in_AI – Student’s trust rating for AI tools

* Purpose – Reason for using AI tools

## 📊 Dashboards Overview

The project contains three interactive dashboards, each focusing on a different aspect of AI tool usage:

### 1. Usage Dashboard

Visualizes the frequency and type of AI tool usage.

Insights include:

Most popular AI tools among students.

Usage patterns across colleges and courses.

Charts used: Bar charts, Pie charts, Column charts.

### 2. Access & Education Dashboard

Explores AI tool accessibility and relationship with education level.

Insights include:

Distribution of AI tool access across students.

How education level or course impacts tool usage.

Charts used: Tree maps, Stacked bar charts, Heat maps.

### 3. Trust & Sentiment Dashboard

Analyzes trust levels in AI tools among students.

Insights include:

Average trust scores per tool and per college.

Correlation between usage frequency and trust.

Charts used: Gauge charts, KPI cards, Line/Area charts.
