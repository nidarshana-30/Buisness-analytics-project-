# SuperMart Grocery Sales – Retail Analytics Excel Project
## 📌 Project Overview

This project analyzes SuperMart grocery sales data to understand sales trends, profit performance, discount patterns, and overall retail analytics. Using Microsoft Excel, three interactive dashboards were created to provide insights into sales, profits, and discounts along with descriptive analysis to help decision-makers optimize operations.

## 🗂 Dataset Description

* Dataset Name: SuperMart Grocery Sales

* Format: Excel (.xlsx)

* Columns include (examples):

  * Order_ID – Unique identifier for each transaction
  
  * Product – Product name or category
  
  * Category – Product category (e.g., Dairy, Snacks)
  
  * Quantity_Sold – Number of units sold
  
  * Unit_Price – Price per unit
  
  * Revenue – Total revenue from the sale
  
  * Discount – Discount applied on the sale
  
  * Profit – Profit earned from the sale
  
  * Sales_Date – Date of the transaction
  
  * Region – Store location or region

## 🧹 Data Cleaning & Preprocessing

Performed using Excel formulas, filters, and pivot tables:

* Removed duplicates – Ensured unique transaction records.

* Handled missing values – Replaced blanks or NA values using Excel functions.

* Standardized formats – Dates, product names, and numeric fields cleaned.

* Derived columns – Calculated Revenue = Quantity_Sold * Unit_Price, Profit Margin = Profit / Revenue.

* Outlier detection – Highlighted extreme values using conditional formatting.

## 📊 Dashboards Overview

The project includes three interactive dashboards in Excel:

### 1. Sales Dashboard

Focuses on total sales trends and performance.

Insights include:

Sales over time (monthly, quarterly, yearly).

Top-selling products and categories.

Regional sales comparison.

Charts used: Line charts, Column charts, PivotTables, and slicers.

### 2. Profit Dashboard

Analyzes profit trends and margins.

Insights include:

Profit contribution by product and category.

Regional profit performance.

Correlation between sales and profit.

Charts used: Bar charts, Area charts, KPI cards, and heat maps.

### 3. Discount & Descriptive Analysis Dashboard

Explores discount patterns and descriptive statistics.

Insights include:

Impact of discounts on sales and profits.

Average, minimum, and maximum values for revenue, discount, and profit.

Customer buying behavior and product performance.

Charts used: Pie charts, Box plots, PivotTables, Conditional formatting.
