# Loan Approval Analysis – Excel Project
## 📌 Project Overview

This project focuses on analyzing loan applications and predicting loan approval status using Microsoft Excel. The goal is to clean and preprocess the dataset, perform exploratory analysis, and derive insights that can help banks and financial institutions make informed lending decisions.

## 🗂 Dataset Description

* Dataset Name: Loan Approval Dataset

* Format: Excel (.xlsx)

* Columns include (examples):

* Loan_ID – Unique identifier for each loan application

* Gender – Applicant gender

* Married – Marital status

* Dependents – Number of dependents

* Education – Education level

* Self_Employed – Whether applicant is self-employed

* ApplicantIncome – Applicant income

* CoapplicantIncome – Coapplicant income

* LoanAmount – Requested loan amount

* Loan_Amount_Term – Term of loan in months

* Credit_History – Credit history (1 = good, 0 = bad)

* Property_Area – Urban, Rural, or Semiurban

* Loan_Status – Target variable (Y = Approved, N = Rejected)

## 🧹 Data Cleaning & Preprocessing

Performed in Excel using formulas, filters, and conditional formatting:

* Removed duplicates – Ensured each application is unique.

* Handled missing values – Replaced blanks or NA values using Excel functions.

* Standardized formats – Dates, categorical variables, and numeric fields cleaned for consistency.

* Derived columns – Created new features such as TotalIncome = ApplicantIncome + CoapplicantIncome.

* Outlier detection – Used Conditional Formatting and charts to identify extreme values.

## 📊 Exploratory Data Analysis (EDA)

Performed using Excel charts, PivotTables, and formulas:

* Loan Status Distribution: Pie/Column charts to visualize approved vs rejected loans.

* Income vs Loan Amount: Scatter plots and box plots to study relationships.

* Credit History Impact: PivotTables to analyze approval rate based on credit history.

* Property Area Analysis: Bar charts to compare approvals in Urban, Rural, and Semiurban areas.

* Education and Employment: PivotTables to explore approval trends across education level and employment type.

## 🔍 Key Insights

* Applicants with good credit history have higher approval rates.

* Higher total income increases chances of loan approval.

* Urban applicants have slightly higher approval rates than Rural and Semiurban areas.

* Self-employed applicants show slightly lower approval rates compared to salaried applicants.

## 🛠 Tools & Techniques

* Formulas: IF, SUM, AVERAGE, VLOOKUP, ISNA, etc.

* PivotTables & Charts: For summarizing and visualizing trends
